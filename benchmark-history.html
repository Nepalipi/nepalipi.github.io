      04 REPRODUCE THE RESULT

      The method is part of the benchmark.

      01 /

      One fixed test population

      The public test is kept separate from our development examples. No cases are selected by an engine’s success or failure.

      02 /

      A shared scoring protocol

      All engines receive the same unchanged Roman token with personalization disabled. Exact match uses Unicode NFC and accepts any reference supplied for that token.

      Empty results and exceptions remain in the denominator. A single-output engine has one chance; top-5 does not invent alternatives.

      03 /

      Train, validate, then test

      The pair model uses TRAIN only; settings use validation. The project-authored typing check was used to diagnose ranking errors and is labeled as a regression check.

      04 /

      Real limits, visible trade-offs

      Local latency is measured inside Node.js after import and three fixed warmups. Google timings include the original network request. Cloud services are excluded from local-speed ranking.

      Accuracy intervals are descriptive 95% Wilson intervals. Related words may be correlated. Google is a dated per-word snapshot; results do not establish general product superiority.

How to read this comparison

First match: the first suggestion equals an accepted spelling. Within three: any of the first three unique suggestions equals one. Within five: any of the first five unique suggestions equals one. Counts beneath the match percentages show the denominator. Character error is first-output edit distance divided by reference characters, pooled across the selected words; lower is better and it can exceed 100%.

Matching uses Unicode NFC and trims surrounding spaces. Errors stay in the captured set’s denominator. Entirely uncaptured sets show “Not captured”. Equal scores share ranks. Category filters recalculate every source on the same subset; the sets overlap, so there is no combined score.

    These are previously observed diagnostic words. Exact spelling agreement is narrower than linguistic correctness, particularly for names and valid alternatives. The sentence and editor checks below have no external baseline.

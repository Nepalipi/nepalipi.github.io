Method & downloads

First match: the first suggestion equals an expected spelling. Within three: an expected spelling appears in the first three suggestions. Within five: an expected spelling appears in the first five suggestions. Higher is better. Counts show matches / tested words.

Each engine receives the same Roman input; its output is scored against fixed corpus references, with personal preferences off. nepscript, Lekhika and Nepali Unicoder return one spelling each. Errors stay in the denominator; missing captures show “Not captured”. Sorting uses actual scores and shares ranks for ties. Character error measures first-output edits per reference character; lower is better.
